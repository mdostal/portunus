# Contributing to Portunus

We welcome contributions to Portunus! Here's how you can help.

## Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## Submitting Pull Requests
1. Fork the repo and create your branch from `dev`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code respects the existing formatting and style.

## Issues
Feel free to submit issues and enhancement requests.

## Architecture
See `docs/architecture.md` for an overview of how Portunus fits into the Pantheon ecosystem.
