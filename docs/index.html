Portunus

A secret broker for the Dostal harness. Named for the Roman god of keys and gates.

View on GitHub

What it is

Portunus ensures that your LLMs and agents never see plaintext secrets. It replaces them with references like {{secret:my-token}} in the agent's context and injects the real value only at the exact moment of an API call or command execution (the boundary).

Quickstart

Install Portunus via pipx or pip:

pipx install portunus

Drop a secret into the local encrypted vault:

portunus drop shared-api-key my-api-key --value-file /path/to/value
portunus state shared-api-key enabled

Resolve at the boundary (exec mode):

portunus resolve --exec curl -H "Authorization: Bearer {{secret:shared-api-key}}" https://api.example.com/data

Architecture

Portunus consists of the OSTIARIUS resolver, the Petitio approval wrapper, and the ARCA vault tier (which supports local encryption and GCP Secret Manager).

Role in Pantheon

As a core plugin for the Dostal harness, Portunus is the fundamental security component ensuring that the Pantheon ecosystem operates with strict least-privilege principles when handling sensitive data.
